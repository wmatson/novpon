# novpon
A sentence-puzzle game

## Why "Novpon"?

The name **Novpon** was generated by applying a simple phoneme substitution to the English pronunciation of **"sentence."** Rather than being derived from Latin or existing words, it comes from transforming the underlying sequence of speech sounds using a fixed rotational cipher over English phonemes, then respelling the result into a pronounceable English-like form.

Because the transformation operates on pronunciation rather than spelling, the name retains a subtle relationship to the game's core concept—guessing complete sentences—while remaining distinctive and not directly descriptive.
